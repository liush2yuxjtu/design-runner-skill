# Orbit SaaS example

This example records the `unified-product-flow` workflow against a real Ardot file.
Twelve screens were moved onto one page, tiled at their original size, and connected
with eleven labeled route arrows. The companion HTML implements the same routes in a
local interactive prototype.

- `index.html`: self-contained interactive prototype
- `orbit-unified-flow.png`: exported Ardot one-page overview
- Live Ardot file: <https://ardot.tencent.com/file/719319930015525>

The example HTML contains no remote requests. Open it directly or serve this directory
with `python3 -m http.server`.
